# Imágenes del sitio

Coloca aquí las fotos y se sirven desde `/images/<archivo>`.

| Archivo sugerido        | Dónde se usa                                   | Tamaño recomendado         |
|-------------------------|------------------------------------------------|----------------------------|
| hero-van.jpg            | `<Hero imageUrl="/images/hero-van.jpg">`       | 2400 x 1400 px, JPG 80%    |
| especialista.jpg        | Bloque junto al formulario (ContactPage)       | 1200 x 1500 px (4:5)       |
| plano-eficiencia.png    | Sustituye la ilustración FloorPlan (opcional)  | PNG con fondo transparente |

El logo va en `public/logo.svg` (o `.png`) y se usa con `<Logo src="/logo.svg" />`.
